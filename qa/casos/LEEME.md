# Casos de prueba (S2)

Un archivo por caso o por grupo coherente: `TC-xxx.md`, con `Origen: SPEC-00x/AC-00y`, REQ del MVP, técnica, oráculo, precondiciones, pasos, datos sintéticos y resultado esperado.

- Un TC sin AC no existe.
- Datos sintéticos; nunca datos personales reales.
- Incluye casos de permisos y de datos sensibles cuando apliquen.
- No escribas pruebas ejecutables aquí: eso es S3.
