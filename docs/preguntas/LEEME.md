# Preguntas abiertas (PREG)

Una pregunta por archivo (`PREG-001.md`, `PREG-002.md`…) con la plantilla del skill `manejo-de-ambiguedades`.

## Reglas

- `Origen`: el agente que la creó (S1, S2, S3, B1–B4, R1, R2) o una persona.
- `Bloquea: sí` solo si impide seguir con el módulo, el caso o la prueba.
- La propuesta del agente se marca como `PROPUESTA`; nunca se trata como decisión.
- La respuesta la da una persona. Al responder, cambia el estado y conserva el archivo.
- No incluyas datos personales reales.
